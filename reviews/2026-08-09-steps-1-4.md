## Also found — excluded by the 15-cap (correctness outranks), tracked here

**Parser (markdown.rs):**
- Multi-line `<!-- tactus: … -->` annotation dropped — `comments_in` scans each `Html` event in isolation and pulldown-cmark emits HTML block content one line per event.
- `##`/`###` headings inside blockquotes/list items create phantom tasks and truncate the enclosing section body (no container-depth tracking in `split_sections`).
- Inline annotation on the heading line itself (`## Fix parser <!-- tactus: … -->`) silently discarded (works for checklist items, not sections).
- Heading-form `### Acceptance` becomes a phantom task; `#### Acceptance` never arms the collector.
- An invisible HTML comment between the `Acceptance:` paragraph and its list disarms collection (`Start(_) => armed = false` matches `Start(HtmlBlock)`).
- `content_hash` over raw bytes → CRLF vs LF makes the same plan hash differently across platforms, contradicting the "stable" doc and risking false resume mismatches.

**Adapter (claude.rs):**
- No `--permission-mode` pinned → deny-by-default rests on an unspecified CLI default (2.x ships an auto-mode classifier).
- An edit agent can commit a `.claude/settings.local.json` that widens permissions for every later task in the run.
- `probe()` advertises hardcoded `Caps` after only `--version` — no real capability probe, so a dropped flag surfaces as per-task errors, not a §19 pre-flight refusal.

**Cross-cutting correctness:** `route::resolve` relabels the first rung `Override → Annotation` when `tier=` equals an override-raised start (misreports decision provenance in the preview); `validate` hardcodes `capacity: not connected` though `pool_names` is parsed; `attempts_per = 0` accepted silently (inconsistent with the timeout-zero rejection); `util::tail` `unwrap_or(start)` can slice off a char boundary for `max < 4` (latent, no current caller); `Workspace::open` doesn't normalize to toplevel so `clean -qfd` is cwd-scoped when run from a subdirectory.

**Altitude (near-term rework warnings):**
- `attempt_task` fuses attempt execution with commit/rollback policy and hardcodes attempt=1 / `PermissionMode::Edit` → step 7's retry-with-resume ladder must dissect it rather than wrap it. Cut a `run_attempt(...) -> AttemptResult` seam now.
- Failure kind is collapsed to `Option<String>` exactly where step 7 (dispatch: RateLimited defers, gate/review retries, Timeout burns an attempt) and step 8 (event payloads) need the structured taxonomy.
- Permission materialization calls concrete `claude::permission_settings` from the engine → step 9's Copilot adapter (argv `--allow-tool`, no settings file) forces a trait change. Move materialization behind `AgentAdapter`.
- `review = { tier = "frontier" }` — DESIGN §17's own example — warns "unknown routing kind `review`"; accept it as a known echoed role before step 6.
- `.git/info/exclude` is the wrong layer; a `.tactus/.gitignore` containing `*` travels with the dir and behaves identically under worktrees (also fixes #8).
- A mid-run environment error discards the whole `RunReport` (committed tasks, spend, session ids); persist per-task incrementally now — the shape step 8's events.jsonl will need.

**Reuse:** `claude::locate` duplicates a weaker PATH walk than `gates::find_program`/`probe_extensions` (already drifted: no PATHEXT); `validate::write_normalized_json` duplicates `engine::write_json`; three graph traversals build three id-indexes (`depends_transitively`, `find_cycle`, `topo_order`); triple temp-git-repo test scaffold (drifted: gates' copy sets no git identity → CI-fragile); test shell builders duplicate `ShellKind::command` (without the raw_arg fix).

**Simplification:** `Draft.ann_found` parallel bool + duplicated annotation intake; unreachable `Config::chain_for` fallback; dead `TaskReport.title`; `Report.task_count` derivable from `plan`; `route` double-relabel; duplicated `ValidateOptions` construction in main; `TaskRun.prompt` split ownership (declared stdin-delivered, engine delivers it separately).

**Efficiency:** `depends_transitively` rebuilds the id-index per (task, artifact) pair; `claude::locate` walks PATH N+1 times per run (cache in a `OnceLock`).

**Conventions:** none — fmt/clippy clean, no `unwrap`/`expect` or `anyhow` outside their allowed places, dependency list intact.
